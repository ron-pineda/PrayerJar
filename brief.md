# PrayerJar

Community prayer app where users submit prayers, pray for others, and leave encouragement. Features AI moderation, guided prayer flows, badges, streaks, and a praise wall for answered prayers.

**Live:** https://prayerjar.org  
**Stack:** Next.js 16 · Neon Postgres · Drizzle · NextAuth · Vercel AI SDK · shadcn/ui  
**Phase:** V2 — mobile UX polish, church finder, expanded community features (23 sprints planned)
