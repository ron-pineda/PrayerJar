Audio Recording Phase 6

Prayer requests can include a voice recording (up to 60 seconds). Requires microphone permission.

Browser requirement: Chrome or Firefox on desktop. Safari iOS 15+. MediaRecorder is not available in all environments — test in a real browser, not a webview.

Recording

  • ✓
    Prayer submission form shows an audio recorder below the photo upload area
  • ✓
    Click record — browser prompts for microphone permission
  • ✓
    Deny microphone permission — recorder shows friendly "Permission denied" message, does not crash
  • ✓
    Grant microphone, start recording — countdown timer from 60s visible
  • ✓
    Stop recording before 60s — audio waveform/player appears in form
  • ✓
    Record for 60s — recording stops automatically, player shown
  • ✓
    Playback of recorded audio works before submitting
  • ✓
    Re-record button clears previous recording

Upload & storage

  • ✓
    Submit prayer with audio — prayer saves with audioUrl pointing to Vercel Blob
  • ✓
    Prayer card shows audio player — clicking play streams the audio
  • ✓
    Prayer submitted without audio — no audio player shown on card
  • ✓
    Upload rate limit: attempt more than 10 audio uploads within 15 minutes — 429 response
API test: POST /api/upload/audio with a multipart/form-data body containing a file field. Accepted types: audio/webm, audio/ogg, audio/mp4, audio/mpeg. Max 5 MB.

v2 REST API Phase 6 API

Public-facing API for external integrations. All endpoints require a valid API key.

GET /api/v2/prayers

  • ✓
    Returns paginated active public prayers — fields: id, content, category, createdAt, isAnonymous, prayerCount
  • ✓
    ?category=healing filter returns only prayers in that category
  • ✓
    ?limit=5&offset=10 pagination works correctly — total field in response
  • ✓
    No API key — 401 Unauthorized
  • ✓
    Invalid category enum value — 400 error response
  • ✓
    Group prayers (groupId not null) are excluded from results

POST /api/v2/prayers

  • ✓
    Submit a prayer via API — 201 response with { prayer: { id, content, category, createdAt } }
  • ✓
    Prayer submitted via API passes through AI moderation — self-harm content returns 422 { error: "moderation", selfHarm: true }
  • ✓
    Missing content field — 400 validation error
  • ✓
    Content over 2000 chars — 400 validation error

GET /api/v2/stats

  • ✓
    Returns aggregate stats: total prayers, active prayers, answered rate, total users
  • ✓
    No API key — 401 Unauthorized
